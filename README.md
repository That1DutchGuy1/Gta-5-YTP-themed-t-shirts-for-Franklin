# YouTube Poop themed tees for Franklin

A hilarious t-shirt texture pack featuring classic YTP characters. Each shirt has a print of a character and an iconic meme quote from them in Comic Sans on it. 

Made by That1DutchGuy

## Installation instructions

* Step 1: Open **OpenIV** and navigate to ```mods\x64v.rpf\models\cdimages\streamedpeds_players.rpf\player_one```. Make sure to enable **Edit Mode**.

* Step 2: Use the **search tool** and type in ```uppr_diff_004``` to filter out all the textures we don't need to look at.

* Step 3: Open any of the ```.ytd``` files from ```uppr_diff_004``` so that the OpenIV Texture Editor window pops open.

* Step 4: **Right-click** with your cursor on the texture name in the left area of the window. You should see a **replace** option. Click that.

* Step 5: Select any of the ```.dds``` texture files from this mod and hit replace. It doesn't matter to the game which vanilla texture you replace because all ```uppr_diff_004``` textures belong to the same t-shirt model in-game.

* Step 6: Hit the **save** button and repeat the steps for the other t-shirts.
